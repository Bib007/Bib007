## Dine distriktskort. Ét samlet overblik.

**Til dig, der administrerer distrikter i en af Jehovas Vidners menigheder.**

Hvilke kort er udleveret? Hvilke er ledige? Hvornår blev et distrikt sidst gennemgået? LTM samler kort, udleveringer og historik ét sted på din egen computer eller Home Assistant.

**[▶ Prøv demoen](https://bib007.github.io/LTM-Local-Territory-Manager/) · [Installer LTM](https://github.com/Bib007/LTM-Local-Territory-Manager/blob/main/docs/INSTALL.md) · [Se projektet](https://github.com/Bib007/LTM-Local-Territory-Manager)**

*Demoen kræver hverken installation eller konto og viser kun opdigtede eksempler.*

[![Overblik i LTM med opdigtede kort, udleveringer og opgaver](https://raw.githubusercontent.com/Bib007/LTM-Local-Territory-Manager/main/assets/screenshots/overblik.png)](https://bib007.github.io/LTM-Local-Territory-Manager/)

### Start enkelt, og byg videre

- **Behold dine papirkort.** Begynd med kortnumre og udleveringer; tilføj adresser og korttegning senere.
- **Få overblik.** Se ledige og udleverede kort, registrer afleveringer, og følg gennemgangene.
- **Kør det selv.** Brug Mac, Windows eller Home Assistant. Registreringerne gemmes på dit eget system.
- **Print efter behov.** Distriktskort, IB-bagsider, S-13 og oversigter.

Dansk er hovedsproget. Engelsk kan vælges i appen, men oversættelsen er stadig under udvikling. Kortbaggrunde, adresseopslag og valgfri billeddeling bruger eksterne tjenester.

### Your territory cards. One clear overview.

I'm building **LTM – Local Territory Manager** with help from OpenAI Codex. It is a free, unofficial tool for managing territory cards, assignments, returns and completion history in congregations of Jehovah's Witnesses.

Start with your existing paper cards, then add addresses and map drawing when you need them. Run LTM on **Mac, Windows or Home Assistant**, with records stored on your own system. Maps, address lookups and optional image sharing use external services.

**[Try the demo](https://bib007.github.io/LTM-Local-Territory-Manager/) · [Installation guide](https://github.com/Bib007/LTM-Local-Territory-Manager/blob/main/docs/INSTALL.en.md) · [Explore the project](https://github.com/Bib007/LTM-Local-Territory-Manager)**

The demo needs no account or installation and uses fictional examples. Danish is the primary language; English is available, with some text and original forms still in Danish.

Feedback from people trying the app is welcome. **[Share feedback](https://tally.so/r/KpY0ZV)** using fictional information only.
